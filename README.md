# python
Este projeto tem como objetivo facilitar a memorização e a fixação dos conteúdos de cada aula de Python do curso em vídeo, aprofundando os assuntos abordados e trazendo explicações complementares, exemplos práticos e exercícios. A ideia é reforçar o aprendizado, ampliar o conhecimento sobre cada tema e garantir uma melhor compreensão do conteúdo estudado.
